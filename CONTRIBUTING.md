# Contributing to SafeNest

Thank you for helping make the Internet safer for children. Contributions of all sizes are welcome: code, selector fixes, documentation, translations and ideas.

## Ground rules

Every SafeNest project must follow our [privacy principles](PRIVACY_PRINCIPLES.md). Pull requests that add tracking, analytics, remote code or unnecessary permissions will not be merged.

## How to contribute

1. Search existing issues first to avoid duplicates
2. Open an issue describing the problem or idea
3. Fork the repository and create a branch from `main`
4. Keep changes small and focused, one topic per pull request
5. Describe what changed and how you tested it
6. Open a pull request using the template

## Browser extensions

- Use Manifest V3 and request the minimum permissions possible
- Do not load external scripts or send network requests
- Test on a clean browser profile before submitting

## Documentation and translations

Guides for parents should be written in plain language, without jargon. Translations are very welcome, Polish first.

## Reporting security problems

Please do not open public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).
