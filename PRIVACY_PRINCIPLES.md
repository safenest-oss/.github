# SafeNest Privacy Principles

These rules apply to every SafeNest project. They exist because tools for children must be trustworthy by design.

1. **No data collection.** Projects must not collect, store or transmit personal data about children or parents.
2. **No telemetry or analytics.** Not even anonymous usage statistics.
3. **No remote code.** Tools must not download and execute code from external servers.
4. **Minimal permissions.** Request only what is strictly needed and explain why in the README.
5. **No accounts.** Tools work without registration.
6. **Local settings only.** Any configuration stays on the user's device.
7. **Transparent behavior.** The README of each project states exactly what the tool does and does not do.

Exceptions require a public discussion and approval from the maintainers.
